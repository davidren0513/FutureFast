# Future Fast 0.4.2 ARM64

## 开关触控与反馈

- AI 分流、节点页自动优选、自动管理页订阅自动更新及自动优选，统一由整张玻璃卡片接收开关操作。标题、滑块、边缘留白及说明文字均可点击；更新间隔和测速间隔保留独立操作。
- 移除开关的默认矩形点击涟漪，共用交互源驱动玻璃滑块的按压形变。设置页整行开关及订阅列表独立开关使用相同反馈。
- 保存成功后立即发布设置状态，不再等待最长约两秒的轮询。轮询与写入串行，避免旧快照覆盖新状态；WorkManager 调度放在状态发布之后。写入失败保持旧值，调度失败保留已经保存的新值并报告错误。
- 滑块切换动画改为 140 毫秒，按压反馈为 100 毫秒；独立开关拖动直接跟随手指。以上是动画配置，并非物理手机的端到端延迟测量。

- 强制停止并重启：AI 分流、自动优选与订阅自动更新状态保持；节点页和自动管理页的同一自动优选设置同步。
- 自动优选卡片的键盘 Tab/Enter、空格及 D-pad 中心激活通过；语义树中每张卡片只有一个开关操作，间隔按钮是独立子操作。
- 设置页整行开关左右边缘点击、订阅列表独立开关左右两端/中部点击与水平拖动均通过。
- APK 签名及 16 KB zipalign 检查通过，native 库仅包含 arm64-v8a。

- 按压前/按住/松手截图及录屏检查：没有默认矩形涟漪，玻璃滑块按压形变和切换正常。证据位于交付目录的 `switch-touch-demo.mp4` 和 `switch-*.png`。

## Not run

- 物理手机端到端触控延迟、大规模订阅性能及全部受支持 Android 版本：本轮使用 API 35 ARM64 模拟器。
- 完整 TalkBack 朗读、全部语言、深浅色/动态配色/单双列的全部组合：本轮未完成这些矩阵，语义树检查不能代替 TalkBack。
- 真实存储满、设备 MMKV 损坏及 WorkManager 失败：通过协调器失败注入测试覆盖状态保留，未在设备上制造这些故障。

初次模拟器运行出现一次设置页 ANR，线程停在 HardwareRenderer 等待模拟器 EGL/Qemu 渲染管道。切换模拟器图形后端后重新执行交互检查；不将模拟器测试推断为所有手机的性能保证。

交付包名 `tech.future.fast`，版本 0.4.2，继续使用此前本地测试证书，可覆盖已有测试版。仅打包 ARM64。
